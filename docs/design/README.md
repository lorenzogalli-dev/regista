# Design review material

Screenshots and real-time captures of the app, made with `web/scripts/capture.mjs`. The rules
they are reviewed against are in `DESIGN.md`.

| Folder | What |
|---|---|
| [`regista/`](regista) | **Current.** The Regista revision (2026-10-18): landing, guided tour, broadcast player with timeline, moment replay and telestration |
| [`archive/d5a/`](archive/d5a) | Archived. First design round (D5a): design system and hero frame on a recorded clip, before the agents existed; earlier type (Archivo / Inter) and accent |
| [`archive/d5b/`](archive/d5b) | Archived. Second round (D5b): broadcast, split view, control room and pages on recorded agent runs, before the Regista revision |

The archived rounds are kept as the record of how the look evolved; they do not show the
current app.
